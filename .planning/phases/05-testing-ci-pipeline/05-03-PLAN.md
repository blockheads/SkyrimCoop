**Step 2: Create Code/tests/integration/fake_player.cpp**

A standalone binary that:

1. Parses command-line args: `--port <port>` (default 10578), `--duration <seconds>` (default 30), `--verify-pid <pid>` (optional, for /proc/pid/mem verification), `--self-test` (headless mode)
2. Creates ConsoleRegistry + GameServer (if no external server), OR connects to an existing server on the given port
3. For self-contained mode (`--self-test`):
   - Instantiates GameServer on localhost
   - Creates MockClient, connects, authenticates
   - Sends scripted movement: walk in a square pattern (4 corners, 5 seconds per side)
   - Each position update: construct ClientReferencesMoveRequest with known coordinates
   - Logs each sent position to stdout
4. If `--verify-pid` is provided:
   - After sending positions, use ProcMemReader to read the Skyrim process memory
   - Look for the remote actor's position in memory (via GameReader or raw pointer chain)
   - Compare expected position with actual position read from memory
   - Print PASS/FAIL with tolerance (5.0 game units)
5. Exits with 0 on success, 1 on failure

The binary is designed to be called by test_ingame_sync.sh which handles Skyrim launch, server startup, and orchestration.

For the self-contained headless test (no Skyrim needed):
```
./fake_player --self-test
```
This just verifies the binary can create a server, connect, authenticate, and send movements -- no /proc verification.

1. **Prerequisites check**: Verify Skyrim SE is installed (check Steam path), verify ptrace works (run smoke_ptrace.sh), verify fake_player binary exists.

2. **Launch Skyrim**: Use the pattern from deploy_and_test.sh to launch Skyrim via Proton with the relay DLL loaded. Wait for the native process to start (poll for the process, timeout 60s).

3. **Find process PID**: Get the Skyrim PID (for /proc/pid/mem access) and the native skyrim-coop process PID.

5. **Run fake_player**: Launch `fake_player --port <server_port> --verify-pid <skyrim_pid> --duration 15`

6. **Collect results**: fake_player exits with 0 (PASS) or 1 (FAIL). Capture stdout for position verification logs.

7. **Cleanup**: Kill Skyrim process, kill native process, report results.
