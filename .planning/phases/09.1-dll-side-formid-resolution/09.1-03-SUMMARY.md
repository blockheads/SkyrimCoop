## Summary

Updated mock_skyrim_loader to send HookEventPackets with formIds in the new arg layout (args[1] = formId). Human-verified the full pipeline end-to-end in Skyrim.

## What Was Built

- **mock_skyrim_loader.cpp**: Updated all mock packets to use the new arg convention (args[0]=pointer, args[1]=formId). Added HOOK_DAMAGE_ACTOR, HOOK_ADD_INVENTORY, HOOK_CHARACTER_CTOR, HOOK_SPAWN_ACTOR mock events with well-known formIds (0x14 = player, 0x00013B90 = Iron Sword).

## Issues Found and Fixed During Verification

During human verification, several bugs were discovered and fixed:

1. **HookEventPacket struct alignment bug** (`_pad[7]` → `_pad[3]`): The 7-byte padding left args at struct offset 12, causing the compiler to insert 4 bytes of implicit padding to reach 8-byte alignment at offset 16. The native side read from payload+8 (expecting offset 12) but args were at payload+12, shifting every uint64_t by 32 bits. Fix: `_pad[3]` puts header(4)+argCount(1)+pad(3)=8, aligning args correctly.

2. **Native payload offset** (`payload + 8` → `payload + 4`): After fixing the padding, the native code's hardcoded payload offset also needed updating.

3. **Constructor hook timing** (ReadFormId before vs after ctor): HookCharacterCtor/Ctor2/SpawnActor were reading formId BEFORE the real constructor ran, so TESForm::formID at +0x14 was always 0. Moved ReadFormId calls to after RealXxx() returns. Even post-ctor, formID is 0 during construction because the engine assigns IDs later during form loading.

4. **HOOK_ACTOR_PROCESS for registration**: Added HOOK_ACTOR_PROCESS to the PointerTable registration path since it fires every frame for loaded actors where formID is guaranteed populated.

5. **CI script fixes**: xmake targets built one at a time (multi-target not supported), correct target name (SkyrimCoopNative), platform config before build, TPTests segfault-on-cleanup handling, MinGW builds moved after --quick exit.

6. **Test script**: Audio muted during automated tests (fAudioMasterVolume=0).

7. **MinGW toolchain**: Fixed escaped shebangs (`#\!` → `#!/`) in wrapper scripts.
