**B. Validate MinGW build of full Tier 1-2 chain:**

Run these commands sequentially to validate the build chain:

```bash
# Configure for MinGW (xPack GCC 14.3.0)
xmake f -p mingw --mingw=$HOME/.local/xPacks/@xpack-dev-tools/mingw-w64-gcc/14.3.0-1.1/.content -m release -y -c

# Build the Tier 1-2 chain bottom-up
xmake build TiltedCore

xmake build CommonLib

xmake build SkyrimCoopNetworking
xmake build AdminProtocol
xmake build Console
xmake build ESLoader
xmake build CrashHandler
xmake build Resources
xmake build SkyrimTogetherServer
```

If any target fails, diagnose and fix the issue. Common issues to watch for:
- Missing `rpmalloc` package: `xmake` should auto-fetch it. If not, run `xmake require rpmalloc`.
- `#include <Windows.h>` case sensitivity: MinGW uses lowercase `<windows.h>`. Fix any occurrences.
- Missing `-fPIC` on Linux-only targets when building under MinGW: This is fine, MinGW doesn't need -fPIC.
- Unresolved symbols: Check which library is missing from deps chain.
