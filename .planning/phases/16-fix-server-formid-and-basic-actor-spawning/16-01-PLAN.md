   - Implement `BroadcastWorldStateSync()`:
     ```cpp
     void CharacterService::BroadcastWorldStateSync() const noexcept
     {
         using namespace std::chrono;
         constexpr auto cSyncInterval = 1000ms;

         auto now = steady_clock::now();
         if (now - m_lastWorldStateSyncTime < cSyncInterval)
             return;
         m_lastWorldStateSyncTime = now;

         WorldStateSync sync;

         auto view = m_world.view<MovementComponent, CharacterComponent>();
         for (auto entity : view)
         {
             auto& movement = view.get<MovementComponent>(entity);
             WorldStateSync::EntityEntry entry;
             entry.ServerId = World::ToInteger(entity);
             entry.Position = movement.Position;
             entry.Rotation.x = movement.Rotation.x;
             entry.Rotation.y = movement.Rotation.z;
             sync.Entities.push_back(entry);
         }

         if (!sync.Entities.empty())
         {
             GameServer::Get()->SendToPlayers(sync);
         }
     }
     ```

   Per D-08: sent every 1 second. Per D-10: event-driven messages remain the fast path, this is the safety net.
   The `SendToPlayers` method without a second arg sends to ALL connected players, matching the broadcast pattern.

3. **Unreliable channel for ServerReferencesMoveRequest (per D-14b):**

   The base `TiltedPhoques::Server::Send(ConnectionId_t, Packet*, EPacketFlags)` already supports `kUnreliable` via enet6 channel 1 (unreliable sequenced per-channel). The problem is that `GameServer::Send(ConnectionId_t, const ServerMessage&)` always calls `Server::Send(aConnectionId, &packet)` with the default `kReliable` flag.

   a. In `Code/server/GameServer.h`, add an overload:

      ```cpp
      void Send(ConnectionId_t aConnectionId, const ServerMessage& acServerMessage,
                TiltedPhoques::EPacketFlags aFlags) const;
      ```

   b. In `Code/server/GameServer.cpp`, implement the overload by copying the existing `Send(ConnectionId_t, const ServerMessage&)` method body but passing `aFlags` to the final `Server::Send(aConnectionId, &packet, aFlags)` call on the last line (currently line ~790). Keep the existing no-flags overload calling the new one with `kReliable` as default to avoid changing all existing call sites.

   c. In `Code/server/Game/Player.h`, add an overload:
      ```cpp
      void Send(const ServerMessage& acServerMessage, TiltedPhoques::EPacketFlags aFlags) const;
      ```

   d. In `Code/server/Game/Player.cpp`, implement:
      ```cpp
      void Player::Send(const ServerMessage& acServerMessage, TiltedPhoques::EPacketFlags aFlags) const
      {
          GameServer::Get()->Send(GetConnectionId(), acServerMessage, aFlags);
      }
      ```

   e. In `Code/server/Services/CharacterService.cpp`, in `ProcessMovementChanges()` (around line 662-666), change the send loop from:

