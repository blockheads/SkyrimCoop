```lua
if is_plat("mingw") then
    -- MinGW uses GCC-style flags, not MSVC
    -- Static linking prevents missing libgcc/libstdc++ DLLs at runtime (see PITFALLS.md)
    add_cxflags("-static", "-static-libgcc", "-static-libstdc++")
    add_ldflags("-static", "-static-libgcc", "-static-libstdc++", {force = true})
    set_arch("x86_64")
    add_defines("_WIN32_WINNT=0x0A00", "WINVER=0x0A00")
    add_defines("NOMINMAX")
    add_syslinks("kernel32")
end
```

Do NOT modify any existing platform blocks. Do NOT remove or change the `add_requires()` calls. Do NOT add `set_runtimes()` in the MinGW block (that is MSVC-only).

**Step 3: Verify configuration**.


Note: Some `add_requires()` packages (cef, discord, sentry-native) may fail to resolve for mingw. This is expected and handled in later phases. The root config just needs to not error on the mingw platform block itself.

**File 2: `Code/tests/feasibility/gate01_skse_plugin/main.cpp`**
Per D-01: Must exercise SKSE APIs (query game version, register for events), not just load and log. The plugin exports `SKSEPlugin_Query` and `SKSEPlugin_Load` with C linkage. It:
1. Receives `SKSEInterface` pointer in `SKSEPlugin_Query`, reads `skseVersion` and `runtimeVersion`
2. Writes results to `Data\SKSE\Plugins\gate01_test.log` via Win32 `CreateFileA`/`WriteFile`
3. In `SKSEPlugin_Load`, attempts to get the messaging interface via `skse->QueryInterface(kInterface_Messaging)` and register a message listener for `kMessage_PostLoad`
4. Has a `DllMain` with `DLL_PROCESS_ATTACH` that calls `DisableThreadLibraryCalls`

Use the SKSE interface struct definitions from the research (C-compatible POD structs with function pointer fields). Define these inline in main.cpp -- do NOT depend on external SKSE headers. The key structures:
- `struct SKSEInterface` with fields: `skseVersion` (uint32_t), `runtimeVersion` (uint32_t), `editorVersion` (uint32_t), `isEditor` (uint32_t), and a `QueryInterface` function pointer `void* (*QueryInterface)(uint32_t)`
- `struct SKSEMessagingInterface` with `interfaceVersion` (uint32_t) and `RegisterListener` function pointer
- Use `__attribute__((dllexport))` for exports (not `__declspec(dllexport)`)
- All exports use `extern "C"` linkage
- Log format: `"GATE-01 PASS: SKSEPlugin_Query called. SKSE=%u Runtime=%u\n"` or `"GATE-01 FAIL: ..."` with reason
