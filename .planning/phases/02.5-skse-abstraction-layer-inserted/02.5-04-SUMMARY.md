## Decisions Made

- **ClientReplayHarness uses bare entt::registry, not World**: World.cpp includes TiltedOnlinePCH.h + SkyrimBridge.h which pull in all SKSE headers. A bare registry with ctx() injection mirrors the exact same pattern World uses, proving the abstraction works without instantiating the full game stack.
- **entt v3.10.0 multiple inheritance dispatch fix**: Discovered that `ctx().emplace<IFormBridge&>(*derivedObj)` stores the raw pointer of `*derivedObj` as `void*` then reinterprets it as `IFormBridge*` — with multiple inheritance this gives the wrong vtable offset. Fix: explicitly pre-cast `IFormBridge& ref = *derivedObj; ctx().emplace<IFormBridge&>(ref);`. Applied to both ClientReplayHarness and World.cpp.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed entt ctx multiple inheritance vtable dispatch in World.cpp**
- **Found during:** Task 2 (ClientReplayHarness implementation + test execution)
- **Issue:** `ctx().emplace<IFormBridge&>(*m_pSkyrimBridge)` stores the wrong vtable pointer when SkyrimBridge uses multiple inheritance, causing all IFormBridge, IPlayerBridge, etc. ctx lookups to dispatch to wrong virtual methods
- **Fix:** Pre-cast each interface reference before ctx().emplace<>: `IFormBridge& ref = *bridge; ctx().emplace<IFormBridge&>(ref);` — applied to both ClientReplayHarness.cpp and World.cpp
- **Files modified:** Code/client/World.cpp, Code/tests/client_replay/ClientReplayHarness.cpp
- **Verification:** All 23 test assertions pass; IEventBridge callback fires correctly via ctx() lookup
- **Committed in:** 96569995 (Task 2 commit)

**2. [Rule 3 - Blocking] Added TiltedCore headers to ReplayBridge.cpp and test files**
- **Found during:** Task 2 (ClientReplayTests build)
- **Issue:** When compiling outside the full client build (no TiltedOnlinePCH.h), encoding struct headers (ActorValues.h, Inventory.h) reference `TiltedPhoques::Map`, `TiltedPhoques::Buffer::Writer` without including TiltedCore
- **Fix:** Added guarded TiltedCore/Stl.hpp + Buffer.hpp + Serialization.hpp + \<optional\> + \<mutex\> to ReplayBridge.cpp (guarded by `#ifndef TILTED_ONLINE_PCH_H`) and to harness/test files
- **Files modified:** Code/client/Bridges/ReplayBridge.cpp, Code/tests/client_replay/ClientReplayHarness.cpp, Code/tests/client_replay/client_replay_tests.cpp
- **Verification:** xmake build ClientReplayTests succeeds with no errors
- **Committed in:** 96569995 (Task 2 commit)
