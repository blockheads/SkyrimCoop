# Phase 02.5 Plan 02: Service Bridge Migration Summary

Bridge injection wired into World constructor; 8 services migrated from direct SKSE API calls to IActorBridge/IFormBridge/IPlayerBridge/IEventBridge/IWorldBridge interfaces using fat-bridge pattern with unique_ptr compilation boundary.

## What Was Built

### World.h / World.cpp — Bridge injection point

`World.h` uses forward declarations for all 5 bridge interfaces and `SkyrimBridge` with `std::unique_ptr<SkyrimBridge> m_pSkyrimBridge`. This is the critical compilation boundary: `World.h` is included by every service `.cpp`, so it must NOT include `SkyrimBridge.h` (which would transitively pull SKSE headers into everything).

`World.cpp` includes `SkyrimBridge.h` and injects all 5 bridge instances into the EnTT registry context:
```
ctx().emplace<IActorBridge&>(*m_pSkyrimBridge);
ctx().emplace<IFormBridge&>(*m_pSkyrimBridge);
// ... etc
```

Services retrieve them via `aWorld.ctx().at<IXxxBridge&>()` in their constructors.

### Task 1 — 4 simplest services

**PartyService**: Replaced single `Cast<TESGlobal>(TESForm::GetById(0xB8EC1))->f = 1.f` with `m_formBridge.SetGlobalValue(0xB8EC1, 1.f)`.

**WeatherService**: Replaced all `Sky::Get()` + `TESWeather*` calls with `m_worldBridge.GetCurrentWeatherId()`, `m_worldBridge.ForceWeather(id, false)`, `m_worldBridge.ReleaseWeatherOverride()`. `FormExists(id)` replaces `Cast<TESWeather>` null checks.

**DiscordService**: All SKSE calls were inside `#ifdef HAS_DISCORD`. Replaced `PlayerCharacter::Get()->locationForm->GetName()` and `pPlayer->GetWorldSpace()` lookups with new `IPlayerBridge::GetPlayerLocationName()` and `GetPlayerWorldSpaceName()` methods added to the interface.

**CommandService**: Replaced `Cast<TESObjectCELL>`, `pWorldSpace->LoadCell(x, y)`, and `PlayerCharacter::Get()->MoveTo(pCell, pos)` with `m_formBridge.FormExists(cellId)`, `m_formBridge.LookupCellByCoords(wsId, x, y)`, and `m_playerBridge.MovePlayerTo(cellId, x, y, z)`.

**SkyrimBridge implementations added**: `ForceWeather` (Sky::Get()->ForceWeather), `ReleaseWeatherOverride`, `GetPlayerLocationName`, `GetPlayerWorldSpaceName`.

### Task 2 — 4 more complex services

**MapService**: Replaced `PlayerCharacter::Get()->SetWaypoint(&pos, pWorldSpace)` and `RemoveWaypoint()` with `m_playerBridge.SetPlayerWaypoint(x, y, z, worldSpaceId)` and `m_playerBridge.RemovePlayerWaypoint()`.

**TransportService**: Replaced 5 SKSE call sites in `OnConnected()`:
- `Cast<TESNPC>(pPlayer->baseForm)->fullName` → `m_formBridge.GetFormName(m_playerBridge.GetPlayerBaseNpcFormId())`
- `ModManager::Get()->mods` iteration → `m_formBridge.GetLoadedMods()` returning `IFormBridge::ModEntry` structs
- `pPlayer->GetWorldSpace()->formID` → `m_playerBridge.GetPlayerWorldSpaceId()`
- `TimeData::Get()->TimeScale->f` etc. → `m_worldBridge.GetGameTimeScale/Year/Month/Day()`

**QuestService**: Most complex migration. Removed `BSTEventSink<TESQuestStartStopEvent>` and `BSTEventSink<TESQuestStageEvent>` base class inheritance from the header entirely. Replaced `EventDispatcherManager::Get()->questStartStopEvent.RegisterSink(this)` and `OnEvent` virtual overrides with `IEventBridge::RegisterQuestStartStopSink(lambda)` and `RegisterQuestStageSink(lambda)`. Internal handlers now receive `(formId, bool)` and `(formId, stageId)` primitives. `ScopedQuestOverride::IsOverriden()` bridged via `m_formBridge.IsQuestOverrideActive()`.

**ActorValueService**: Replaced all `Cast<Actor>(TESForm::GetById(formId))` + `pActor->*` calls with `m_actorBridge.*` calls. `CreateActorValuesComponent` signature changed from `Actor* apActor` to `uint32_t aFormId`. `Utils::GetByServerId<Actor>` replaced with new `Utils::GetFormIdByServerId(serverId)` helper (ECS-only, no SKSE) + bridge actor method calls.

### New bridge methods added

**IFormBridge**: `ScriptSetQuestStage`, `SetQuestStopped`, `IsQuestStagesEmpty`, `IsQuestOverrideActive`, `GetLoadedMods()`, `ModEntry` struct.

**IWorldBridge**: `GetGameTimeScale`, `GetGameYear`, `GetGameMonth`, `GetGameDay`.

**IPlayerBridge**: `GetPlayerLocationName`, `GetPlayerWorldSpaceName`.

**SkyrimBridge**: All new methods implemented with real SKSE calls. Also implemented previously-TODO'd: `KillActor`, `RespawnActor`, `SetActorValue`, `GetGameTimeHours`.
