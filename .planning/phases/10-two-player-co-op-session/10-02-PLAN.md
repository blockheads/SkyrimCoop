<objective>
Implement CMD_SET_POSITION execution in the relay DLL on the game thread, and add SKYRIM_COOP_PORT env var for explicit port binding.

Purpose: The native process sends CMD_SET_POSITION commands over TCP to move remote player characters, but the DLL's DrainCommandQueue is a stub (per D-07). This plan implements the command decoder and hooks it into the game thread via HOOK_ACTOR_PROCESS on the player character (formId 0x14) per D-08. Only CMD_SET_POSITION is implemented per D-09. Additionally, per D-11, the DLL must support explicit port binding via the SKYRIM_COOP_PORT environment variable so two instances can use distinct ports (host=9667, client=9668).

Output: When the native process sends a CMD_SET_POSITION, the DLL applies it to the target actor on the next game frame. DLL binds to SKYRIM_COOP_PORT if set, otherwise falls back to ephemeral port 0.
</objective>

    **Step 2: Implement DrainCommandQueue in relay_main.cpp**

    Replace the existing stub (lines 118-126) with:
    ```cpp
    void DrainCommandQueue()
    {
        using TSetPosition = void (__fastcall*)(void*, void*);
        auto pRealSetPosition = reinterpret_cast<TSetPosition>(GetRealSetPosition());

        g_commandQueue.Drain([pRealSetPosition](const CommandSlot& cmd) {
            switch (cmd.opcode) {
            case CMD_SET_POSITION: {
                void* pActor = reinterpret_cast<void*>(cmd.args[0]);
                if (!pActor || !pRealSetPosition) break;

                uint32_t posXBits = static_cast<uint32_t>(cmd.args[1]);
                uint32_t posYBits = static_cast<uint32_t>(cmd.args[1] >> 32);
                uint32_t posZBits = static_cast<uint32_t>(cmd.args[2]);

                float pos[3];
                memcpy(&pos[0], &posXBits, sizeof(float));
                memcpy(&pos[1], &posYBits, sizeof(float));
                memcpy(&pos[2], &posZBits, sizeof(float));

                pRealSetPosition(pActor, pos);
                break;
            }
            default:
                RelayLog("[SkyrimCoopHooks] Unknown command opcode=0x%04X\n", cmd.opcode);
                break;
            }
        });
    }
    ```

    Remove the `[[maybe_unused]]` attribute and `static` keyword from DrainCommandQueue (it needs external linkage for hook_trampolines.cpp to call it).

    **Step 3: Hook DrainCommandQueue into game thread via HookActorProcess**

    Per D-08: Call DrainCommandQueue when HOOK_ACTOR_PROCESS fires for the player character (formId 0x14).

    ```cpp
    static void __fastcall HookActorProcess(void* apThis, float aDelta)
    {
        if (ReadFormId(apThis) == 0x14)
        {
            DrainCommandQueue();
        }

        uint64_t args[3] = { reinterpret_cast<uint64_t>(apThis),

        SendHookEvent(HOOK_ACTOR_PROCESS, 3, args);
        RealActorProcess(apThis, aDelta);
    }
    ```
