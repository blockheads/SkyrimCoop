       ```cpp
           m_messagesReceived++;
           if (m_pRouter) {
               // JoinClient receives raw enet payload -- no leading byte to skip
               // (unlike loopback which has a packet-type prefix byte)
               // ServerMessageRouter::OnServerMessage expects the format WITH the
               // leading byte (it skips byte 0). So we need to prepend a dummy byte.
               std::vector<uint8_t> padded(aSize + 1);
               padded[0] = 0; // dummy packet-type byte
               memcpy(padded.data() + 1, apData, aSize);
               m_pRouter->OnServerMessage(padded.data(), static_cast<uint32_t>(padded.size()));
           }
       }
       ```
       IMPORTANT: Verify whether JoinClient's OnConsume data has the same format as loopback. The loopback path prepends a byte via TiltedPhoques::Server::Send. The enet path in TiltedPhoques::Client::OnConsume may or may not have this prefix. Read the TiltedPhoques Client base class to determine. If the enet path already includes the prefix byte, just pass through directly without padding. If not, prepend the dummy byte as shown. The safest approach: try direct passthrough first (m_pRouter->OnServerMessage(apData, aSize)), check if it parses. If factory.Extract fails, the router logs "failed to extract" -- that means you need the padding.
