    **InventoryService.h / .cpp** — Handles 6 hook types for inventory changes.

    ```cpp
    class InventoryService {
    public:
        InventoryService(GameReader& reader);
        void OnHookEvent(const HookEventPacket& pkt);
        void Update(float deltaTime);
    private:
        GameReader& m_reader;
    };
    ```

    Hook event handling:
    - `HOOK_ADD_INVENTORY` (args: actor ptr, item ptr, count): Read item formId via `m_reader.ReadFormId(args[1])`, read actor formId from pointer table, send inventory add message.
    - `HOOK_EQUIP` (args: actor ptr, item form ptr): Read both formIds, send equip message.
    - `HOOK_UNEQUIP` (args: actor ptr, item form ptr): Read formIds, send unequip message.
    - `HOOK_PICK_UP` (args: actor ptr, ref ptr): Read formIds, send pickup message.
    - `HOOK_DROP_OBJECT` (args: actor ptr, ref ptr): Read formIds, send drop message.
    - `HOOK_REMOVE_INV_ITEM` (args: ref ptr, item ptr, count): Read formIds, send remove message.

    For each hook: the raw pointer args arrive as uint64_t. Use `m_reader.ReadFormId(ptr)` to get the formId from each pointer. Use `m_reader.LookupPointer(formId)` when needed to cross-reference.

    For item counts: the count argument is typically an integer passed as uint64_t. Extract with `static_cast<int32_t>(args[2])`.

    Remote inventory application (receiving sync from other players): Send CMD_EQUIP_ITEM / CMD_UNEQUIP_ITEM / CMD_ADD_ITEM / CMD_REMOVE_ITEM commands to DLL via TCP.

    ```cpp
    class MagicService {
    public:
        MagicService(GameReader& reader);
        void OnHookEvent(const HookEventPacket& pkt);
        void Update(float deltaTime);
    private:
        GameReader& m_reader;
        // Track active spell casts for each actor

            uint32_t spellFormId;
            float startTime;
        };
        std::vector<ActiveCast> m_activeCasts;
    };
    ```

    Hook event handling:
    - `HOOK_SPELL_CAST` (args: caster ptr, spell ptr): Read caster and spell formIds. Track as active cast. Send spell cast sync message.
    - `HOOK_INTERRUPT_CAST` (args: caster ptr): Find active cast by caster, remove. Send interrupt message.
    - `HOOK_ADD_TARGET` (args: target ptr, target data ptr): Read target formId, read magic effect data from target data pointer via memory reads. Send target add message.
    - `HOOK_APPLY_EFFECT` (args: actor ptr, magic item ptr, effect ptr): Read all three formIds plus effect magnitude/duration from memory. Send effect application message.
    - `HOOK_REMOVE_SPELL` (args: actor ptr, spell ptr): Read formIds, send spell removal message.

    Remote spell application (when another player casts):
    - Receive spell cast notification from network
    - Send CMD_CAST_SPELL command to DLL with target actor ptr and spell formId
    - Send CMD_ADD_SPELL / CMD_REMOVE_SPELL for spell list changes

    Key memory reads for magic:
    - SpellItem formId: `m_reader.ReadFormId(spellPtr)` at offset 0x14
    - SpellItem spell type: Read at SpellItem-specific offset (determine from MagicItem.h or SpellItem.h in game struct headers)
    - Effect magnitude: Read float from MagicEffect struct at known offset
    - Effect duration: Read float from MagicEffect struct at known offset

    Study the current `MagicService.cpp` carefully for the exact message types sent (e.g., `SpellCastRequest`, `InterruptCastRequest`) and replicate the same network sync behavior but using GameReader reads instead of direct pointer access.
