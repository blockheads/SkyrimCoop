    This is a mechanical conversion across all 8 services. The changes are uniform and follow a single pattern.

    **Header (.h) changes (all 8):**
    - Replace `struct HookEventPacket;` forward declaration with `#include "nlohmann/json_fwd.hpp"`
    - Change signature: `void OnHookEvent(const nlohmann::json& aMsg);`
    - If Plan 03 already updated the headers, verify and adjust as needed.

    **CharacterService.cpp changes:**
    - Add `#include "nlohmann/json.hpp"`, `#include "json_protocol.h"`
    - Replace OnHookEvent body. Current code switches on `static_cast<HookOpcode>(aPkt.header.opcode)`. New code:
      ```cpp
      void CharacterService::OnHookEvent(const nlohmann::json& aMsg) {
          const auto& op = aMsg["op"].get_ref<const std::string&>();
          if (op == JsonOp::kActorAdded) {
              HandleActorAdded(aMsg["ptr"].get<uint64_t>(), aMsg["form_id"].get<uint32_t>());
          } else if (op == JsonOp::kActorRemoved) {
              HandleActorRemoved(aMsg["ptr"].get<uint64_t>(), aMsg["form_id"].get<uint32_t>());
          } else if (op == JsonOp::kSetPosition) {
              uint32_t formId = aMsg["form_id"].get<uint32_t>();
              if (formId != 0) {
                  float px = aMsg["x"].get<float>();
                  float py = aMsg["y"].get<float>();
                  float pz = aMsg["z"].get<float>();
                  float rx = aMsg["rx"].get<float>();
                  float rz = aMsg["rz"].get<float>();
                  m_positionCache[formId] = {glm::vec3(px, py, pz), glm::vec2(rx, rz)};
              }
          } else if (op == JsonOp::kCharacterCtor) {
              HandleCharacterCtor(aMsg["ptr"].get<uint64_t>(), aMsg["form_id"].get<uint32_t>());
          } else if (op == JsonOp::kSpawnActor) {
              HandleSpawnActor(aMsg["ptr"].get<uint64_t>(), aMsg["form_id"].get<uint32_t>());
          } else if (op == JsonOp::kDeathItems) {
              HandleDeathItems(aMsg["ptr"].get<uint64_t>(), aMsg["form_id"].get<uint32_t>());
          } else if (op == JsonOp::kPerformAction) {
              HandlePerformAction(aMsg["actor_form_id"].get<uint32_t>(), aMsg["action_form_id"].get<uint32_t>());
          } else if (op == JsonOp::kActorProcess) {
              // Pointer table handled in main.cpp already
          }
      }
      ```
    - Replace command senders (SendSetPosition, SendPlayAnimation) to build JSON + m_client.SendJsonLine():
      ```cpp
      void CharacterService::SendSetPosition(uint64_t aActorPtr, const glm::vec3& aPos, const glm::vec2& aRot) {
          nlohmann::json cmd = {
              {"op", JsonOp::kCmdSetPosition},
              {"actor_ptr", aActorPtr},
              {"x", aPos.x}, {"y", aPos.y}, {"z", aPos.z}
          };
          m_client.SendJsonLine(cmd);
      }
      ```
    - Remove all `FloatFromU64` / `U64ToFloat` usage -- JSON gives native floats.

    **WeatherService.cpp changes:**
    - OnHookEvent dispatches on op string: kWeatherChange, kSetWeather, kForceWeather
    - Reads named fields: sky_ptr, weather_form_id, weather_ptr, override, accel
    - Command senders (CMD_FORCE_WEATHER) become JSON builders using m_client.SendJsonLine

    **CalendarService.cpp changes:**
    - OnHookEvent handles kSimulateTime

    **QuestService.cpp changes:**
    - OnHookEvent: currently empty or minimal. Keep same pattern with JSON.

    **CombatService.cpp changes:**
    - OnHookEvent handles: kDamageActor (read damage float), kProjectile, kAddTarget
    - Command senders (CMD_DAMAGE_ACTOR, CMD_LAUNCH_PROJECTILE) become JSON

    **InventoryService.cpp changes:**
    - OnHookEvent handles: kAddInventory, kPickUp, kDropObject, kEquip, kUnequip, kRemoveInvItem, kActivate, kLockChange
    - Each reads named fields: actor_form_id, item_form_id, count, etc.
    - Command senders (CMD_EQUIP_ITEM, CMD_UNEQUIP_ITEM, CMD_ADD_ITEM, CMD_REMOVE_ITEM, CMD_ACTIVATE, CMD_LOCK_CHANGE) become JSON

    **ActorValueService.cpp changes:**
    - OnHookEvent handles: kRegenAttr -- reads form_id, type (int), value (float)
    - Command sender (CMD_SET_ACTOR_VALUE) becomes JSON

    **MagicService.cpp changes:**
    - OnHookEvent handles: kSpellCast, kInterruptCast, kRemoveSpell, kApplyEffect
    - Reads: caster_form_id, spell_form_id, refund (bool), etc.
    - Command senders (CMD_CAST_SPELL, CMD_ADD_SPELL, CMD_REMOVE_SPELL) become JSON

    **Key pattern for all services:**
    - Replace `switch (static_cast<HookOpcode>(aPkt.header.opcode))` with `const auto& op = aMsg["op"]; if (op == JsonOp::kXxx)`
    - Replace `aPkt.args[N]` with `aMsg["field_name"].get<type>()`
    - Replace `FloatFromU64(aPkt.args[N])` with `aMsg["field_name"].get<float>()` -- no conversion needed
    - Replace CommandPacket construction with nlohmann::json object + m_client.SendJsonLine()

    NOTE: Although this task touches 16 files, the changes are mechanical and follow a single uniform pattern. Each service gets the same three changes: (1) include swap, (2) OnHookEvent body rewrite from switch to if-chain, (3) command sender rewrite from binary to JSON.
