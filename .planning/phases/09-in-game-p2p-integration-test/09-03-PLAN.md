Create tests/test_two_player.sh as a new executable bash script. This script launches two Skyrim instances (host + join) using separate Proton prefixes to prove the full P2P co-op pipeline.

The script structure follows the same patterns as test_ingame_sync.sh (INI injection, Proton launch, relay wait, cleanup trap) but implements a sequential two-instance protocol.

Key design elements:

1. CONFIGURATION: Same SKYRIM_DIR, PROTON_DIR, COMPAT_DATA, STEAM_DIR, PLUGINS, RELAY_INFO, DLL_LOG paths as test_ingame_sync.sh. Additional variables:
   - COMPAT_DATA_JOIN="/tmp/skyrimcoop_test_join_$$" (cloned Proton prefix for join instance)
   - GAME_SERVER_PORT=10578
   - MONITOR_DURATION=30

2. HELPERS: Copy info/pass/fail/warn from test_ingame_sync.sh. Add setup_test_logs() creating /tmp/skyrimcoop-twoplayer-XXXXXX/ with HOST_SKYRIM_LOG, HOST_NATIVE_LOG, JOIN_SKYRIM_LOG, JOIN_NATIVE_LOG files. Add fail_with_logs() that tails last 20 lines of available logs. Add wait_for_gameserver_port() using ss -ulnp polling.

3. INI INJECTION: Same inject_starting_cell/restore_skyrim_ini as test_ingame_sync.sh but parameterized with $1 as the ini_path argument instead of hardcoded $SKYRIM_INI.

4. CLEANUP: trap EXIT calls cleanup() which restores both INI files, kills all Skyrim/skyrim-coop processes, removes RELAY_INFO, removes COMPAT_DATA_JOIN directory, and optionally removes TEST_RUN_DIR.

5. CLONE PREFIX: clone_join_prefix() does cp -a "$COMPAT_DATA" "$COMPAT_DATA_JOIN" and sets SKYRIM_INI_JOIN to the join prefix Documents path.

6. SEQUENTIAL LAUNCH PROTOCOL (8 stages):
   Stage 1: check_prerequisites (same checks as test_ingame_sync.sh)
   Stage 2: clone_join_prefix
   Stage 3: inject_starting_cell for both INI files
   Stage 4: Launch host Skyrim via "$PROTON_DIR/proton" run, pgrep -f SkyrimSE.exe for PID (120s timeout)
   Stage 5: Wait for relay_info.json, read host port/pid, launch host skyrim-coop --pid $HOST_SKYRIM_PID --port $HOST_RELAY_PORT, wait_for_gameserver_port 10578
   Stage 6: Launch join Skyrim with STEAM_COMPAT_DATA_PATH=$COMPAT_DATA_JOIN WINEPREFIX=$COMPAT_DATA_JOIN/pfx, wait for relay_info.json to change (poll until pid differs from host pid captured earlier, 90s timeout)
   Stage 7: Read join relay port/pid, launch join skyrim-coop --pid $JOIN_SKYRIM_PID --port $JOIN_RELAY_PORT --connect 127.0.0.1:10578
   Stage 8: Monitor both native processes for MONITOR_DURATION seconds (verify both alive with kill -0 every 5s)

7. RELAY_INFO COLLISION HANDLING: wait_for_join_relay() function takes host_pid as arg, polls RELAY_INFO until the pid value differs from host_pid (meaning join DLL has overwritten it). Host's native process is already connected before join launches, so the overwrite is safe.

8. JOIN SKYRIM PID DETECTION: After launching join Skyrim, use pgrep to find the second SkyrimSE.exe PID. Since host is already running, get all PIDs and pick the one that is NOT HOST_SKYRIM_PID.

9. ARGS: Parse --keep-logs and --help. Default KEEP_LOGS=false.

10. Make executable: chmod +x tests/test_two_player.sh

Final success message: echo "=== SkyrimCoop Two-Player Integration Test PASSED ==="
