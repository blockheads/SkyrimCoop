Extend fake_player.cpp with the following changes (per D-02):

1. **Add new Config fields:**
   - `int bots = 1;` — number of concurrent bot clients
   - `bool verifyBroadcast = false;` — enable broadcast verification
   - `bool metrics = false;` — enable latency/throughput output
   - `int tickRate = 5;` — movements per second per bot (default 5 = 200ms sleep)

2. **Add CLI parsing in ParseArgs():**
   - `--bots N` sets `cfg.bots`
   - `--verify-broadcast` sets `cfg.verifyBroadcast = true`
   - `--metrics` sets `cfg.metrics = true`
   - `--tick-rate N` sets `cfg.tickRate`

3. **Create a BotContext struct:**
   ```cpp
   struct BotContext {
       int id;
       std::unique_ptr<MockClient> pClient;
       std::atomic<uint64_t> movesSent{0};
       std::atomic<uint64_t> broadcastsReceived{0};
       std::atomic<bool> running{true};
       std::atomic<bool> failed{false};
       std::string failReason;
   };
   ```

4. **Create a RunMultiBot() function** that replaces RunExternal() when `bots > 1`:
   - Spawns N `std::thread` workers, each creating a MockClient
   - Each bot connects to `::1:PORT`, authenticates with username `"FakeBot-{id}"`, and sends movement in a loop at `tickRate` Hz
   - Each bot uses WalkPattern::GetPosition() with a phase offset: `elapsed + id * 2.0f` so bots walk different paths
   - Main thread waits for `duration` seconds, then sets all `running = false`

5. **Add broadcast counting in MockClient** (or a derived class `BroadcastTrackingClient`):
   - Override OnConsume() to also count ServerReferencesMoveRequest opcodes received
   - Store count in the BotContext's `broadcastsReceived` atomic
   - The opcode for ServerReferencesMoveRequest: look it up in Opcodes.h (it's in the kServer* range)

6. **Implement --verify-broadcast logic:**
   - After all bots finish, check that each bot received at least `(bots - 1) * duration * tickRate * 0.5` broadcasts (50% threshold accounts for timing)
   - If any bot received 0 broadcasts, FAIL
   - Print per-bot broadcast counts

7. **Implement --metrics output:**
   - Print to stdout: `bot_id,moves_sent,broadcasts_received,connect_time_ms`
   - Track connect time as duration from ConnectByIp() to m_connected becoming true
   - Final line: `total,{sum_sent},{sum_received},{avg_connect_ms}`

8. **Keep RunExternal() for single-bot mode** (bots=1, no broadcast verification) — backwards compatible with test_ingame_sync.sh.

9. **Update main():** If `cfg.bots > 1` or `cfg.verifyBroadcast`, call RunMultiBot(). Otherwise call RunExternal() or RunSelfTest() as before.
