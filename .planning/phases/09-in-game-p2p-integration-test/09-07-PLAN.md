<objective>
Fix hook destabilization that crashes Skyrim after Riverwood cell load.

Purpose: The relay DLL installs 31 MinHook trampolines on game functions. During level loading (Riverwood cell), some of these hooks corrupt game state and cause a crash. Since the core P2P testing only requires a handful of hooks (actor lifecycle + position), this plan adds a "minimal hooks" mode that installs only the essential hooks needed for basic actor sync. This is toggled via environment variable so the full hook set remains available for future development.

Output: Relay DLL with configurable hook installation -- essential-only mode (7 hooks) vs full mode (31 hooks). Essential hooks cover: ActorProcess, SetPosition, CharacterCtor, CharacterCtor2, SpawnActorInWorld, AddDeathItems. Default mode is essential-only for stability.
</objective>
