**2. Add `SkyrimTogetherClientDLL` target to `Code/client/xmake.lua`** — After the existing `build_client("SkyrimTogetherClient")` call, add:

```lua
-- MinGW-only: Thin DLL wrapper that links the static client lib
-- and exports SKSE plugin entry points (SKSEPlugin_Version, SKSEPlugin_Load, DllMain)
-- Equivalent of immersive_launcher's /WHOLEARCHIVE but producing a DLL instead of EXE
if is_plat("mingw") then
    target("SkyrimTogetherClientDLL")
        set_kind("shared")
        set_group("Client")
        set_basename("SkyrimTogetherClient")  -- output: SkyrimTogetherClient.dll

        add_files("skse_entry.cpp")
        add_deps("SkyrimTogetherClient")

        -- Pull ALL symbols from the static lib (MinGW equivalent of /WHOLEARCHIVE)
        add_ldflags("-Wl,--whole-archive", {force = true})
        on_load(function (target)
            -- The actual archive path is resolved by xmake from the dep
            -- We need to ensure --whole-archive wraps the static lib
        end)
        -- Close the --whole-archive scope after the static lib
        add_ldflags("-Wl,--no-whole-archive", {force = true})

        -- Same syslinks as the static lib needs for linking
        add_syslinks(
            "version",
            "dbghelp",
            "kernel32",
            "ws2_32",
            "winmm",
            "iphlpapi",
            "crypt32",
            "user32",
            "advapi32",
            "shell32",
            "ole32",
            "stdc++fs")

        -- Include paths needed for skse_entry.cpp
        add_includedirs(".", "../external/")

        -- Inherit packages from the static lib dependency chain
        add_packages("rpmalloc", "spdlog", "entt", "glm", "minhook", "xbyak",
                     "hopscotch-map", "cryptopp", "enet6", "imgui")
        if not is_plat("mingw") then
            -- This branch never runs (we're inside is_plat("mingw")),
            -- but kept for documentation clarity
        else
            add_includedirs("../external/mem", {public = false})
        end
end
```

Important implementation notes:
- The `--whole-archive` / `--no-whole-archive` flags sandwich the static library link. xmake passes deps in order, so the static lib symbols get pulled in.
- `set_basename("SkyrimTogetherClient")` ensures the output is `SkyrimTogetherClient.dll` (not `SkyrimTogetherClientDLL.dll`).
- The `stdc++fs` syslink is needed because `skse_entry.cpp` uses `<filesystem>`.
- Additional syslinks (`ws2_32`, `winmm`, etc.) are needed because the static lib's transitive dependencies require them at final link time.
- If xmake does not correctly sandwich the dep with `--whole-archive`, use `on_link` or `add_ldflags("-Wl,--whole-archive -lSkyrimTogetherClient -Wl,--no-whole-archive")` as a fallback. Test by checking `x86_64-w64-mingw32-nm SkyrimTogetherClient.dll | grep SKSEPlugin` shows exported symbols.
